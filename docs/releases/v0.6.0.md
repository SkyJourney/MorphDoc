# MorphDoc · 墨呈 v0.6.0

## 核心更新

- 新增可编辑 DOCX 导出，保留纸张、页边距、字体、段落、代码块、图片、
  Mermaid、ECharts、封面、页眉页脚和页码配置。
- 建立通用主题到 DOCX 样式翻译引擎，14 套内置主题通过真实 Word/WPS
  无修复打开、编辑和逐页视觉门禁。
- 新增可扩展 Markdown 基础工具栏，支持标题、强调、代码、引用、多行列表、
  任务列表、分隔线及 M×N 表格。
- PDF 与 DOCX 统一收口到“导出”子菜单，并提供独立顶部进度提示。

## 发行与兼容性

- 产品更名为“墨呈”，英文名 MorphDoc；保留原 NSIS 安装身份并迁移到新的
  默认安装目录、快捷方式和开始菜单目录。
- Desktop 内置固定 Pandoc 3.9.0.2 最小运行时；字体包可在安装向导中选择，
  也提供独立安装器与 ZIP。
- Docker 镜像内置固定 Chromium、Pandoc 与正式字体包，支持完全离线部署。
- 正式字体资产转由仓库固定目录管理（公开版已取消 Git LFS）。

## 问题修复

- 修复精确预览放大后右侧缺少固定留白的问题。
- 修复保存、另存为和导出的默认路径优先级。
- 修复 Desktop DOCX 图片捕获可能超时的问题。
- 修复品牌改名后安装器仍继承旧安装目录的问题。
- 统一主题展示名称，默认主题保持 GitHub。

## 验证结论

- 全项目测试、类型检查、生产构建和空白检查通过。
- 14 套主题生产 PDF/DOCX 与六组纸张、方向、页边距视觉矩阵通过。
- Web API、Desktop ZIP、覆盖安装后的真实安装版均完成 PDF/DOCX 导出。
- Word/WPS 可编辑性、字体嵌入、封面独立分页和页眉页脚位置门禁通过。

当前 Windows 安装器未进行 Authenticode 签名；公开
网络分发前建议增加代码签名。

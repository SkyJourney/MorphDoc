# MorphDoc · 墨呈 v0.6.7

> 发布日期：2026-11-27 · 变更范围：[v0.6.6...v0.6.7](https://github.com/SkyJourney/MorphDoc/compare/v0.6.6...v0.6.7)

## 概述

本版本修复精确分页（PDF 与精确预览）中表格跨页处的几类版面错误：表格在页边界附近多出空白页并整张表从头重放、表格被整体推到下一页而上一页空间足够、标题孤零零留在页底、列很多的宽表被从单元格中间切开。这些问题在“政企正式·可研报告”等主题、A3 横屏的长文档里被发现。

- **根因是项目与 Paged.js 的行为约定不一致，不是某个主题或某张表格的问题。** Paged.js 内置过滤器会把所有带内联样式的元素误判为“不显示”，表格稳定化写入的样式正好触发它；另外 Paged.js 只从 CSS 规则读取强制分页声明，项目里多处用内联样式表达的强制分页实际没有任何效果。
- **没有逐个打补丁，而是建立了一层分页适配层**：输入边界的内联样式守卫、强制分页的统一入口、分页之后的不变量检查与修复。设计、已验证的行为契约与扩展方法见 `docs/PAGINATION.md`。
- **宽表适配页宽**：比页面内容区更宽的表格先压缩单元格内边距、必要时按比例缩列，不再被切成两段。
- **连续标题紧接整页高的图表或流程图**：整串标题现在与媒体同页。修复内联样式守卫时暴露出此前被掩盖的老问题（图表被重复渲染），已一并根治。

用户可见的变化只发生在上述版面场景；Markdown 解析、主题、导出配置、DOCX 导出与桌面端交互均未改动。DOCX 路径显式关闭了宽表适配，并有契约测试锁定。

用户的研报在可研主题、A4 竖向下由 169 页（含 14 行重复、1 张空白页、3 个孤立标题）变为 77 页，上述指标全部归零；A3 横屏在 Electron 150 下为 40 页，4.1、5.1 接缝正常。

本版本不是零风险的内部重构：改动面包括分页主流程，所以验证覆盖了与上一个正式版并排的 155 次渲染对比和反向验证，详见下文。

- 修复 Paged.js 分页接缝导致的表格重复、空页与标题孤立 ([#22](https://github.com/SkyJourney/MorphDoc/pull/22))

<details><summary>#22 的完整说明</summary>

用户在 A3 横屏精确分页、“政企正式·可研报告”主题下打开一份研报，发现 4.1 表格跨页处
多出空页并整表重放，5.1 表格被整体推到下一页。根因不是某个主题或某张表格，而是
项目与 Paged.js 的几处行为约定不一致；这次没有逐个打补丁，而是建立了分页适配层。

根因：
- Paged.js 内置过滤器把所有带内联 style 的元素标成“不显示”。表格稳定化会写
  table-layout: fixed，表格因此被跳过，标题的 break-after: avoid 标记落到表格之后
  的图表上；图表放不下时断点越过整张表回退，表格被整体推走，续页空白并整表重放。
- Paged.js 只从 CSS 规则解析 break-before/break-after，内联样式被完全忽略。项目里
  多处用内联样式表达强制分页，实际没有任何效果。

新增能力：
- 内联样式守卫：在内置过滤器运行前暂存内联样式、运行后原样还原。
- 分页意图 API（forceBreakBefore/forceBreakAfter）：强制分页的唯一入口，用语义
  属性加共享 CSS 映射表达；表格行恢复由内联样式加拆表改为该 API。
- 分页不变量运行器：表格行丢失（可修复）、整行重复（只检测）、标题孤立在页末
  （可修复，覆盖连续标题与表格内断开两种情形）；统一的轮数上限与严重程度。
- 表格适配页宽：超过页面内容区的宽表先压缩内边距、再按比例缩列，避免被 Paged.js
  从单元格中间切开；DOCX 路径显式关闭，并有契约断言锁定。
- 连续标题抽象 getPrecedingHeadingChain：整页缩放的高度计算、回填的媒体组顶部、
  回填的强制换页判定共用“媒体块及其前面整串连续标题”。

回归修复：内联样式守卫让“标题必须跟着媒体走”的约束终于生效，却暴露出整页缩放只扣除
紧邻一个标题的老问题：二级标题紧跟三级标题再接整页高图表时，图表被重复渲染并触发
Unable to layout item。上一个正式版没有重复（章标题被孤立在上一页，掩盖了问题）。
已用上述共享抽象根本修复。

不迁移的部分：封面锚点改用强制分页会多出空白页（A5 横向投标封面由 4 页变 5 页），
保持原状并写明原因；整页图片与图表仍用内联写法，已记录为待优化项。

测试：
- 新增 e2e：Paged.js 行为契约、对全部静态夹具与四组主题纸张配置的内容守恒（文字

  表格适配页宽的列数扫描、整页缩放媒体、连续标题、被约束封面、表格图表接缝。
- 新增源码守卫：禁止新增内联强制分页，白名单逐项写明真实状态。
- 夹具由 generate.mjs 确定性生成，并有防漂移与结构守卫测试。
- 预览引擎单测 206 个，覆盖率阈值已上调。

- 研报在可研主题 A4 竖向由 169 页、14 行重复、1 张空白页、3 个孤立标题变为 77 页、

### 本阶段发现并纠正的问题

- 修复内联样式守卫后，`##` 紧跟 `###` 再接整页高图表的写法会让图表被重复渲染，并触发 Paged.js 的 `Unable to layout item`。上一个正式版没有重复（章标题被孤立在上一页，掩盖了问题），所以这是本次开发引入的回归，已在合并前根治，没有进入任何正式版。
- 守恒检查最初排除了图表文字，所以重复渲染没被抓到。现在新增了“媒体块个数分页前后必须相等”和“Paged.js 不得报无法布局”两条通用检查，对全部静态夹具和多组主题纸张配置生效。

## 已知缺陷与待优化项

完整说明与改进方向见 `docs/PAGINATION.md` 第 7 节。

| 编号 | 类别 | 内容 |
| --- | --- | --- |
| PG-1 | 已知缺陷，可优化 | 列表项的引导行落在页底、子项在下一页。例如可研主题 A3 横屏的研报第 32 页末，“4. 远期期权（控制仓位、跟踪试点节奏）：”是页上最后一行，它的子项排到了下一页。上一个正式版的同一位置没有此现象，是内容后移、页边界恰好落在这里造成的。**不影响内容完整性，仅为版面瑕疵**，计划下个版本单独立项。 |
| PG-2 | 待优化，小版本迭代 | 整页缩放的图片、图表、流程图仍使用对 Paged.js 无效的内联强制分页，靠“撑满一页后自然溢出”才表现正确；迁移到统一入口的前提已具备，但修复连续标题之后尚未重新评估。 |

其余为设计限制，不影响内容正确性：快速预览的增量编辑路径不运行分页不变量（以 PDF 与精确预览为准）；窄页面下标题串加表头与首行比一页还高时，标题无处可去；超宽表只保证不溢出、不切行，A4 竖向放 21 列数字会逐位折行，建议改用横向纸张。

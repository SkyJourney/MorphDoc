# MorphDoc · 墨呈 v0.6.5

> 发布日期：2026-11-20 · 变更范围：[v0.6.4...v0.6.5](https://github.com/SkyJourney/MorphDoc/compare/v0.6.4...v0.6.5)

## 概述

本版本的主要目标是**让发布流程闭环、版本号只在一处维护**：

- 版本号统一来源：根 `package.json` 与 `apps/desktop/package.json` 是唯一手写处，
  其余位置读取它们或使用占位符，`pnpm test` 中的 `version:check` 拦截写死的版本号。
- 发布工具链闭环：`pnpm run version:set <版本>` 从 git 生成 CHANGELOG 章节与本发行说明，
  人工部分用占位标出，未补全时发布校验拒绝推送标签。
- 发布前的 CI 检查增加 `Actionlint`，守住工作流语法与表达式；Release 工作流改为只由版本
  标签与手动触发运行。

- 修复渲染器与公式显示的已知缺陷并补充回归测试 ([#2](https://github.com/SkyJourney/MorphDoc/pull/2))

<details><summary>#2 的完整说明</summary>

修复由 Markdown 夹具矩阵与真实浏览器逐像素对比发现的 7 个缺陷，每个都带回归测试，
并做了反向验证（撤销修复后新测试必须失败）；涉及白名单的改动另做了变异验证。

渲染器：
- 无效 Front Matter 第二次渲染起不再报错，整段 YAML 被当作正文：gray-matter 在
  解析前写入全局缓存，失败后条目残留。改为 matter(source, {}) 绕过缓存。缓存还以
  浅拷贝返回，多次调用会共享同一个 data 对象。
- 公式中的根号、可拉伸箭头、宽重音符、上下括号、划线被安全过滤器移除，sqrt(pi)
  显示为 pi。按 KaTeX 0.16 与 0.19 的实际输出精确放行 svg、path、line 与 11 个属性；
  不放行 xmlns、href、use、image、foreignObject、animate、set、style 元素和事件属性。
- 正文里的普通单词 footnote、mermaid、katex，以及代码块中展示的 class 文本，被误判
  为启用对应特性。改为只匹配真实标签的 class。

公式显示（真实 Chromium 中 139 个公式逐像素对比发现）：
- 安全过滤器还丢弃了若干结构性内联样式：left 缺失时 vec、hat 偏向一侧；
  color:transparent 缺失时 phantom 把本该隐藏的内容显示出来；border-*、bottom、
  margin 缺失时数组的列分隔线消失、rule 缩成零尺寸。按 KaTeX 的实际取值逐属性
  放行，color 只放行 transparent，border-right-style 只放行 solid 与 dashed，
  margin 只接受 1 到 4 个以 em 为单位的数值。
- 生成公式标记的 KaTeX 与提供样式表的 KaTeX 版本错开：渲染器经 @mdit/plugin-katex
  使用 0.19，apps/web 打包的样式表来自 0.16；0.19 给 19 个 class 加了 katex- 前缀，
  旧样式表不认识，上标、下标、分式字号全部偏大，数组 hline 不显示。130 个公式中
  95 个在应用实际使用的样式表下显示不一致，且没有任何报错。apps/web 升到
  ^0.19.1，并新增版本一致性守卫，降级后会失败。
- 预览引擎的全局 svg max-width:100% 把 vec 的箭头 SVG 夹成 0 宽。为 .katex svg 设置
  max-width:none。

测试与约定：
- 新增 front-matter-cache、feature-detection、sanitize-svg、katex-style-parity 四个
  测试文件与 math-svg、math-layout、prose-feature-words 三个夹具；移除全部 it.fails。
- e2e 新增公式场景，在真实 Chromium 中断言 SVG 被绘制、重音符有非零偏移、phantom
  内容透明、数组分隔线与 rule 尺寸非零、上下标字号小于根字号；math、math-svg、
  math-layout 三张视觉基线逐张目视审阅后入库。
- WORKFLOW.md 新增“缺陷必须伴随回归测试，覆盖率只升不降”，并补充视觉基线更新时的
  取图规则：已有基线不匹配时 Playwright 不会覆盖，e2e-screenshots 里的同名文件仍是
  旧基线，新图在 e2e-report 的 actual。覆盖率阈值随渲染器覆盖率上升而抬高。

产品决定：公式一律使用主题颜色。color、colorbox 等用户颜色命令的颜色被移除，这是
有意为之，避免为颜色值设计额外规则，并保持 PDF 与走 Pandoc 的 DOCX 公式一致，
已在 katex-style-parity 测试中固化。

验证：最终提交上 CI（7 项，含三平台测试与覆盖率）与 E2E（17 项）通过；Stability
（三平台各 2 轮，不稳定用例 0 个）、E2E 重新生成基线与发布演练三个手动入口已从
分支真实运行并通过，重新生成的 7 张基线与已入库的逐字节一致。

尚未验证：标签发布从未真实执行，publish 任务与 gh release create 只经过 actionlint
校验；视觉基线只在 Linux 上比对；桌面产物仍未做代码签名。

</details>
